<HbAlert type="info">React projects use <a href="https://react.hbui.dev" target="_blank" rel="noopener noreferrer">Hummingbird React</a>, the official React component library for Hummingbird. It includes the Hummingbird styles and replaces the JavaScript plugins with React components, so there is no need to install <code>@hummingbirdui/hummingbird</code> or initialize any scripts.</HbAlert>

## Quick start

Create a new React (Vite) project with Hummingbird React, Tailwind CSS and dark mode already set up:

<Example lang='bash' showPreview={false} code={`npx create-hummingbird-react-app@latest my-app --template vite`} />

With pnpm, yarn or bun, run `pnpm create hummingbird-react-app`, `yarn create hummingbird-react-app` or `bun create hummingbird-react-app` instead. See the <a href="https://react.hbui.dev/docs/getting-started/cli" target="_blank" rel="noopener noreferrer">CLI documentation</a> for all options.

To add Hummingbird React to an existing project, follow the steps below.

## Installation

#### 1. Install Tailwind CSS

Follow the <a href="https://tailwindcss.com/docs/installation/using-vite" target="_blank" rel="noopener noreferrer">official installation guide</a> to install Tailwind CSS in a Vite project.

#### 2. Install Hummingbird React

Install Hummingbird React via preferred package manager:

<Example lang='bash' showPreview={false} code={`npm install @hummingbirdui/react`} />

#### 3. Import CSS

Import Tailwind CSS and Hummingbird React in the main CSS file. No Tailwind configuration is needed, because the package registers its own source paths.

<Example lang='css' showPreview={false} filePath="src/index.css" code={`@import "tailwindcss";
  @import "@hummingbirdui/react";`} />

#### 4. Use components

Import any component and use it in the application.

<Example lang='js' showPreview={false} filePath="src/App.tsx" code={`import { Button } from "@hummingbirdui/react";

  export default function App() {
    return <Button color="primary">Click me</Button>;
  }`} />

## Dark mode

#### 1. Add the dark variant

Hummingbird uses class-based dark mode: a `dark` class on `<html>` switches the theme. Register the variant after the style imports.

<Example lang='css' showPreview={false} filePath="src/index.css" code={`@custom-variant dark (&:where(.dark, .dark *), .dark);`} />

#### 2. Set the initial theme

Add this script to the `<head>` of `index.html`. It applies the saved theme before the page renders, so there is no flash of the wrong theme.

<Example lang='html' showPreview={false} filePath="index.html" code={`<head>
    <!-- ... -->
    <script>
      const theme = localStorage.getItem("theme");
      document.documentElement.classList.toggle(
        "dark",
        theme === "dark" ||
          (theme !== "light" &&
            window.matchMedia("(prefers-color-scheme: dark)").matches),
      );
    </script>
  </head>`} />

#### 3. Add a theme toggle

`DarkThemeToggle` switches between light and dark mode, saves the choice and keeps browser tabs in sync. For a custom control, use the <a href="https://react.hbui.dev/docs/customize/dark-mode" target="_blank" rel="noopener noreferrer">useThemeMode hook</a>.

<Example lang='js' showPreview={false} filePath="src/components/Navbar.tsx" code={`import { DarkThemeToggle } from "@hummingbirdui/react";

  export function Navbar() {
    return <DarkThemeToggle />;
  }`} />

## React Router (framework mode)

React Router in framework mode follows the same steps, with three differences. For a single-page app that uses React Router as a library, follow the Vite steps above.

Create a new project with the `react-router` template:

<Example lang='bash' showPreview={false} code={`npx create-hummingbird-react-app@latest my-app --template react-router`} />

In an existing project:

- **Tailwind CSS** is already set up in projects created with `create-react-router`. Otherwise, follow the <a href="https://tailwindcss.com/docs/installation/framework-guides/react-router" target="_blank" rel="noopener noreferrer">official installation guide</a>.
- **The CSS imports** and the dark variant go in `app/app.css`.
- **The initial theme** comes from `ThemeModeScript` instead of an inline script. Render it in the `Layout` export of `app/root.tsx`, and add `suppressHydrationWarning` to `<html>`, because the script updates it before React hydrates.

<Example lang='js' showPreview={false} filePath="app/root.tsx" code={`import { ThemeModeScript } from "@hummingbirdui/react";
  import { Links, Meta, Scripts, ScrollRestoration } from "react-router";

  export function Layout({ children }: { children: React.ReactNode }) {
    return (
      <html lang="en" suppressHydrationWarning>
        <head>
          <meta charSet="utf-8" />
          <meta name="viewport" content="width=device-width, initial-scale=1" />
          <Meta />
          <Links />
          <ThemeModeScript />
        </head>
        <body>
          {children}
          <ScrollRestoration />
          <Scripts />
        </body>
      </html>
    );
  }`} />
