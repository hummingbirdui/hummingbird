## Overview

The Rating component uses radio inputs to capture a numeric value. Stars before and including the selected value are filled via CSS.

---

## Anatomy

A rating consists of:

- `rating` → flex container
- `rating-input` → star-shaped radio inputs

---

## Basic Rating

The number of star inputs determines the maximum rating. Add `checked` to one to set a default value.

<Example code={`<div class="rating">
    <input type="radio" name="rating-basic" value="1" class="rating-input" />
    <input type="radio" name="rating-basic" value="2" class="rating-input" />
    <input type="radio" name="rating-basic" value="3" class="rating-input" checked />
    <input type="radio" name="rating-basic" value="4" class="rating-input" />
    <input type="radio" name="rating-basic" value="5" class="rating-input" />
  </div>
`} />

## Half Stars

Use `rating-mask-half-1` and `rating-mask-half-2` on consecutive inputs to enable half-star precision. Each pair of half inputs forms one visual star.

<Example code={`<div class="rating">
    <input type="radio" name="rating-half" value="0.5" class="rating-input rating-mask-half-1" />
    <input type="radio" name="rating-half" value="1" class="rating-input rating-mask-half-2" />
    <input type="radio" name="rating-half" value="1.5" class="rating-input rating-mask-half-1" />
    <input type="radio" name="rating-half" value="2" class="rating-input rating-mask-half-2" />
    <input type="radio" name="rating-half" value="2.5" class="rating-input rating-mask-half-1" />
    <input type="radio" name="rating-half" value="3" class="rating-input rating-mask-half-2" checked />
    <input type="radio" name="rating-half" value="3.5" class="rating-input rating-mask-half-1" />
    <input type="radio" name="rating-half" value="4" class="rating-input rating-mask-half-2" />
    <input type="radio" name="rating-half" value="4.5" class="rating-input rating-mask-half-1" />
    <input type="radio" name="rating-half" value="5" class="rating-input rating-mask-half-2" />
  </div>
`} />

## Best Practices

- Each group of stars must share the same `name` attribute
- Use `rating-mask-half-1` / `rating-mask-half-2` consecutively for half-star precision (each pair is one visual star)
- Add `checked` to a star input to preselect a value
- The number of inputs directly matches the star count (or twice that for half-stars)
