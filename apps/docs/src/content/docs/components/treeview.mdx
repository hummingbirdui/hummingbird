## Overview

The Treeview component displays hierarchical data in a collapsible tree structure. It works with the [collapse](/docs/components/collapse/) plugin for expand / collapse behavior.

---

## Anatomy

A treeview consists of:

- `treeview` → root container
- `treeview-item` → single tree node
- `treeview-content` → clickable row area (label, icon, etc.)
- `treeview-toggle` → chevron button to expand / collapse children
- `treeview-group` → nested sub-list

## Best Practices

- Use `treeview-toggle` only on items with children (those containing a `treeview-group`).
- Leaf nodes can omit the toggle for a cleaner look.
- Use `treeview-selected` to indicate the currently active item.
- Nest `treeview-group` inside `treeview-item` to maintain proper indentation.
- The collapse plugin handles expand/collapse — use `data-bs-toggle="collapse"` and `data-bs-target` on `.treeview-toggle`.
