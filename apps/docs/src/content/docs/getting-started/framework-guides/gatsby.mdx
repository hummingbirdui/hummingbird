<HbAlert type="info">React projects use <a href="https://react.hbui.dev" target="_blank" rel="noopener noreferrer">Hummingbird React</a>, the official React component library for Hummingbird. It includes the Hummingbird styles and replaces the JavaScript plugins with React components, so there is no need to install <code>@hummingbirdui/hummingbird</code> or initialize any scripts.</HbAlert>

## Quick start

Create a new Gatsby project with Hummingbird React, Tailwind CSS and dark mode already set up:

<Example lang='bash' showPreview={false} code={`npx create-hummingbird-react-app@latest my-app --template gatsby`} />

To add Hummingbird React to an existing project, follow the steps below.

<HbAlert type="info">Gatsby 5 supports Node.js versions below 26. With pnpm, Gatsby also needs <code>nodeLinker: hoisted</code> in <code>pnpm-workspace.yaml</code>, and pnpm 11 or later needs its dependency build scripts approved under <code>allowBuilds</code>. Projects created with the CLI include both.</HbAlert>

## Installation

#### 1. Install Tailwind CSS

Follow the <a href="https://tailwindcss.com/docs/installation/framework-guides/gatsby" target="_blank" rel="noopener noreferrer">official installation guide</a> to install Tailwind CSS in a Gatsby project with `gatsby-plugin-postcss`.

#### 2. Install Hummingbird React

Install Hummingbird React via preferred package manager:

<Example lang='bash' showPreview={false} code={`npm install @hummingbirdui/react`} />

#### 3. Import CSS

Import Tailwind CSS and Hummingbird React in the main CSS file. No Tailwind configuration is needed, because the package registers its own source paths.

<Example lang='css' showPreview={false} filePath="src/styles/global.css" code={`@import "tailwindcss";
  @import "@hummingbirdui/react";`} />

Then import the CSS file in `gatsby-browser.js`.

<Example lang='js' showPreview={false} filePath="gatsby-browser.js" code={`import "./src/styles/global.css";`} />

#### 4. Use components

Import any component and use it in a page.

<Example lang='js' showPreview={false} filePath="src/pages/index.js" code={`import { Button } from "@hummingbirdui/react";

  export default function IndexPage() {
    return <Button color="primary">Click me</Button>;
  }`} />

## Dark mode

#### 1. Add the dark variant

Hummingbird uses class-based dark mode: a `dark` class on `<html>` switches the theme. Register the variant after the style imports.

<Example lang='css' showPreview={false} filePath="src/styles/global.css" code={`@custom-variant dark (&:where(.dark, .dark *), .dark);`} />

#### 2. Set the initial theme

Add `ThemeModeScript` to the document `<head>` in `gatsby-ssr.js`. It applies the saved theme before the page renders, so there is no flash of the wrong theme.

<Example lang='js' showPreview={false} filePath="gatsby-ssr.js" code={`import { ThemeModeScript } from "@hummingbirdui/react";

  export const onRenderBody = ({ setHeadComponents }) => {
    setHeadComponents([<ThemeModeScript key="theme-mode-script" />]);
  };`} />

#### 3. Add a theme toggle

`DarkThemeToggle` switches between light and dark mode, saves the choice and keeps browser tabs in sync. For a custom control, use the <a href="https://react.hbui.dev/docs/customize/dark-mode" target="_blank" rel="noopener noreferrer">useThemeMode hook</a>.

<Example lang='js' showPreview={false} filePath="src/components/Navbar.js" code={`import { DarkThemeToggle } from "@hummingbirdui/react";

  export function Navbar() {
    return <DarkThemeToggle />;
  }`} />
